你的 Roborock，
放進「家庭」App。

這是一個 Homebridge 外掛，透過 HomeKit 或 Matter 把 Roborock 掃地機器人放進「家庭」App。用 Siri 或自動化開始打掃；就算 Roborock 雲端斷線，也能在家裡的網路上繼續控制。

開始使用 在 GitHub 查看

免費、開放原始碼。支援 Homebridge 1.6 以上；Matter 需要 Homebridge 2。

掃地機器人
要打掃的房間

試試看：選擇房間，或不選就打掃全屋。分房清掃需要 Matter 與 iOS 18.4 以上。

雲端斷線，照樣能用

Roborock 雲端只在登入和讀取裝置清單時需要。控制指令會透過家裡的網路直接送到掃地機器人；如果 Homebridge 啟動時連不上雲端，外掛會用先前儲存的裝置清單啟動。場景等雲端功能會在雲端恢復後自動回來。

  1. 「家庭」AppiPhone、iPad、Mac 或 HomePod
  2. HomeKit 或 Matter
  3. Homebridge執行這個外掛
  4. 你家的網路
  5. Roborock 掃地機器人連在你的 Wi-Fi 上

外掛需要先成功連線啟動過一次，才會儲存裝置清單。從其他 Roborock 帳號分享給你的掃地機器人，只能透過雲端控制。

在「家庭」App 裡能做什麼

每台掃地機器人都會帶著它實際具備的控制項和資訊出現。

  • 開始、停止、送回充電座

    透過 HomeKit 時，掃地機器人會以風扇樣式的方塊出現：打開就開始打掃，關閉就停止並返回充電座。Siri、場景和自動化也都能用。

  • 電量、充電與錯誤

    電量、充電狀態和低電量警告。掃地機器人回報錯誤或離線時會被標示出來。

  • 你的 Roborock 場景

    在 Roborock App 建立的場景會變成開關，點一下或用自動化就能跑完整套流程。

  • 基座洗拖布

    基座能清洗拖布的機型會多一個開關：可以開始或停止清洗，而且不論從哪裡啟動，只要基座正在清洗就會顯示為開啟。

  • 濾網與刷子

    透過 HomeKit 時，顯示濾網、主刷和邊刷的剩餘壽命，快用完時會提醒你。

  • 目前房間送到 MQTT

    可選擇把正在打掃的房間發佈到你的 MQTT broker，讓燈光或其他自動化跟著掃地機器人走。

Matter：真正的掃地機器人控制 Beta

為掃地機器人選擇 Matter，Apple「家庭」就會把它顯示成掃地機器人而不是風扇：可以選擇要打掃的房間、切換吸塵、拖地或兩者並行，還能送它回充電座。Google Home、Alexa 和 SmartThings 也能使用。

Apple「家庭」對 Matter 掃地機器人的支援還很新。配對時會出現「未經認證的配件」警告，iOS 更新後偶爾也會有些小狀況。想要最穩定的體驗，請繼續使用 HomeKit。

每台分別選擇

在外掛設定中載入裝置，再為每台掃地機器人三選一。

  • HomeKit (HAP)

    預設選項。穩定、熟悉的風扇樣式方塊。

  • Matter (Beta)

    原生的掃地機器人控制和分房清掃。需要開啟 Matter 的 Homebridge 2；分房清掃需要 iOS 18.4 以上。

  • 略過

    不把這台放進 Apple「家庭」，例如別人家分享給你的掃地機器人。

把掃地機器人改成另一種協定時，配件會重新建立，之後需要重新設定它的房間和自動化。

只在米家 App 裡？

外掛看得到的是你 Roborock 帳號裡的掃地機器人。只在米家（Xiaomi Home）App 設定的掃地機器人不在這個帳號裡，所以不會出現。

幾分鐘就能設定好

  1. 安裝外掛

    在 Homebridge UI 打開「外掛」，搜尋 Roborock Vacuum，安裝 homebridge-roborock-vacuum。

  2. 登入

    在外掛設定輸入 Roborock App 的 email，用密碼或 email 收到的驗證碼登入。區域會自動偵測。

  3. 選擇並重新啟動

    按下 Load devices，為每台掃地機器人選擇 HomeKit、Matter 或略過，然後重新啟動 Homebridge。

需要 Homebridge 1.6 以上，以及 Node.js 18.20、20.15、22 或 24。Matter 需要開啟 Matter 的 Homebridge 2。 完整說明文件（英文）
